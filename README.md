# Signature Staking [SIGN]

Website of the Cardano stake pool **Signature Staking**, ticker **[SIGN]**: https://staking.da-sign.com

## How to contribute

- **Delegate your ADA to [SIGN].** Open a wallet that supports delegation (Lace, Eternl or Daedalus), search for the ticker **SIGN** and confirm. Your ADA never leaves your wallet and you can change pool at any time.
- **Coming soon: Signature Staking Service**, a free game on the blockchain. Stay tuned.
- **Spread the word** and report problems with the site by opening an issue in this repository.
